# Definition of Done propuesta

Estado: propuesta para acordar con el equipo y adaptar a los requisitos del profesor. Se aplica a todas las historias del incremento; los criterios de aceptación concretos siguen en cada issue.

Una historia está terminada cuando:

- [ ] Su comportamiento cumple todos los criterios de aceptación acordados.
- [ ] Funciona desde la interfaz y persiste los datos cuando corresponde.
- [ ] La API valida datos y protege el acceso a información ajena.
- [ ] La compilación y las pruebas relevantes pasan; los errores detectados están resueltos.
- [ ] La PR ha sido revisada por otra persona del equipo.
- [ ] El código está integrado en la rama de trabajo acordada (en este proyecto, main).
- [ ] La documentación necesaria para usarlo y mantenerlo está actualizada.
- [ ] El incremento puede ejecutarse y demostrarse desde una instalación reproducible.
- [ ] Existe trazabilidad entre issue, PR y evidencia de pruebas.

No cerrar una historia solo porque tiene código o un documento. La Review inspecciona el incremento y permite adaptar el producto; no sustituye la DoD ni debe convertirse en una aprobación administrativa obligatoria de cada cambio.

## Antes de seleccionar trabajo para el sprint

Guía práctica de preparación, no un artefacto obligatorio de Scrum:

- Entender el valor y el alcance.
- Acordar criterios comprobables.
- Identificar dependencias y dividir trabajo demasiado grande.
- Estimar conjuntamente y elegir según capacidad real.

## Uso del tablero

Mantener el flujo del proyecto: Product Backlog → Sprint Backlog → To Do → In Progress → In Review → Completed.

1. Product Backlog: trabajo posible, ordenado por el Product Owner.
2. Sprint Backlog/To Do: trabajo seleccionado por Developers para el objetivo del sprint.
3. In Progress: alguien está trabajando en él.
4. In Review: implementación disponible y pendiente de revisión/verificación.
5. Completed: cumple la DoD; cerrar el issue con enlace a la PR.

Scrum no prescribe estos nombres de columnas ni obliga a usar puntos de historia. Son convenciones de vuestro equipo.
